# CHANGELOG da base (exemplo fictício)

Toda mudança registra o que mudou, por quê e quem decidiu. Os agentes derivados declaram a versão
da base que usam; quando ela muda, os anexos de cada agente são atualizados.

## 1.0

- Base inicial: identidade (N1), posições com camada e firmeza (N1/N2), linhas vermelhas (N1),
  pendências (N2).
- Origem: sessão de validação com a candidata, entrevistas publicadas e currículo.
- Decisão registrada: segurança pública fica em F1 (princípio, sem proposta).

## Como registrar a próxima versão

```
## 1.1
- O que mudou: <arquivo, item>
- Por quê: <fonte nova, decisão, correção de teste>
- Quem decidiu: <função>
- Agentes afetados: <lista>
```
